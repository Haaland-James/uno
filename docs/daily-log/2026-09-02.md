## Context recap
`uno` is a rental marketplace with four roles (Renter, Landlord, Agent, Admin),
each with its own auth flow and console. Stack: Next.js 14 App Router, Prisma +
PostgreSQL (Supabase/PostGIS), NextAuth (email OTP + Google OAuth), Cloudinary
(photos), Mapbox (maps/geocoding), Upstash (rate limiting), Resend (email),
Tailwind + Radix UI, Zustand.

Build history to date (see `docs/PROJECT_SUMMARY.md`):
- **Stage 0** — Next.js scaffold, Figma tokens, base UI components.
- **Stage 1** — Prisma schema, migrations, seed.
- **Stage 2** — Email-OTP authentication.
- **Stage 3** — Search/feed, favourites, saved searches, share, toasts.
- **Maps** — Mapbox search integration, PostGIS map APIs, geocoding proxies.
- **Listings** — Kind-aware listing wizard (residential/commercial/land),
  drafts, edit-by-section, status actions, verification flow.
- **Agent role** — Agent auth, console, owners, analytics stub, specializations.
- **Admin** — Admin panel, agents console, users, reports system, listing
  reassignment.
- **Account** — Profile/settings wired to DB, Google OAuth, password auth,
  account deactivation.
